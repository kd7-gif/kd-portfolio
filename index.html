Nigerian State-Level Drought Forecasting System

My final-year thesis at Bowen University. A deep learning platform that forecasts drought for all 37 Nigerian states up to six months ahead, using the SPEI drought index built from CHIRPS rainfall and CRU climate data, and presented on an interactive React dashboard.

  • Trained GRU and Transformer encoder models in PyTorch at 3- and 6-month horizons
  • FastAPI service runs the models; an Express API feeds the dashboard
  • Best model (GRU, 3-month) cut forecast error 19.5% below a persistence baseline on held-out test data
  • New monthly climate data can be ingested through the API without code changes

ChopDash Food Delivery Platform

Three apps in one product: customers order from 28 restaurants and stores, kitchens run orders from a live dashboard, and riders claim and complete deliveries on their phones. Every status change reaches the right screens instantly.

  • Live tracking over WebSockets, with each browser joining only the rooms it is allowed to see
  • Dish and restaurant recommendations learned from order history with item-to-item cosine similarity
  • Paystack payments with prices always worked out on the server
  • Race-safe updates, so only one rider can claim a delivery even with simultaneous taps
  • Hosted demo runs entirely in the browser, with one-tap switching between customer, kitchen and rider

Turnup Events & Ticketing Platform

Guests discover events, see which friends are going and buy tickets in seconds. Hosts create events, sell tickets, check guests in with QR codes at the door and watch arrivals on a live dashboard.

  • Tickets held for 10 minutes at checkout with one atomic database update, so a sold-out show can never oversell
  • QR check-in from any phone camera; each ticket admits once, even if two doors scan the same screenshot
  • Live check-in dashboard over WebSockets with arrivals every 15 minutes and a feed of every scan
  • Host tools for events, ticket types, promo codes, door staff and co-hosts, with sales charts
  • Hosted demo runs entirely in the browser, with one-tap switching between guest, host and door
