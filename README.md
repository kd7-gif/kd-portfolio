# KD Daramola Portfolio

My personal portfolio: shipped projects, what I'm building next, background and contact.

Plain HTML, CSS and JavaScript. No build step and no dependencies.

## Run it locally

Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Structure

```
index.html     page markup
css/style.css  all styles and animations
js/main.js     loader, scroll reveals, nav, galleries, counters
js/ring.js     3D hero ring (Three.js from CDN, CSS fallback if unavailable)
img/           project screenshots
```
